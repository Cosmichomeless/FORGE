Crear una aplicación colaborativa de gestión de proyectos inspirada en herramientas como Linear/Jira, pero con alcance controlado.

- Next.js
- React
- TypeScript
- Java
- Spring Boot
- PostgreSQL

- Azure

- Proyectos

- Estados y prioridades

- Comentarios
- Notificaciones
- Activity log
- Búsqueda y filtros
- Dashboard
- API REST documentada
- Tests
- Docker
- CI/CD
- Despliegue real
